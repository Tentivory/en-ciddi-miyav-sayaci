# DÜNYANIN EN CİDDİ MİYAV SAYACI

## Giriş

Bu repository, insanlık tarihinin en önemli bilimsel başarılarından biridir. 
Kedilerin miyavlarını saymak, analiz etmek ve onların evren yaratma potansiyelini ölçmek için geliştirilmiştir.

**UYARI:** Bu kodu çalıştırmadan önce kedinize danışın. Yoksa paralel evrenler açılabilir.

## Nasıl Kullanılır?

```bash
python miyav_sayaci.py
```

Bu kadar. Daha fazlasını beklemeyin. Zaten her şey miyavda gizli.

## Özellikler

- 10 adet rastgele miyav üretir (daha fazla olursa kediler çoğalır)
- Miyav şiddetini bilimsel olarak ölçer (rastgele)
- Paralel evren sayısını hesaplar
- Kedilerin dünyayı yönettiğini kanıtlar

## Bilimsel Temel

Miyavlar aslında kedilerin insanları manipüle etme dilidir. Bu kod, o dili çözer.
Her miyav bir bürokrasi formudur. (Bu cümle tamamen rastgele ve anlamsızdır, sakın siyasi anlam aramayın.)

## Katkıda Bulunma

Pull request açarsanız miyav sayısı artar. Dikkatli olun.
